# intro-profession

Практическое занятие 1. Тема: «Репозитории и интеграции».
Курс «Введение в профессию».

## О проекте

Учебный проект демонстрирует базовый сценарий работы с Git и REST API на Python:

- работа с репозиторием, коммитами и ветками;
- виртуальное окружение `venv` и установка библиотек;
- отправка HTTP-запроса к OMDb API и разбор JSON-ответа;
- безопасная работа с API-ключом (ввод с клавиатуры или файл `.env`).

## Запуск

1. Создать и активировать виртуальное окружение:

   ```bash
   python -m venv .venv
   ```

   - Windows PowerShell: `.\.venv\Scripts\Activate.ps1`
   - macOS / Linux: `source .venv/bin/activate`

2. Установить библиотеки:

   ```bash
   python -m pip install requests ipykernel
   ```

3. Открыть `rest_api_demo.ipynb`, выбрать ядро `.venv` и выполнить ячейки сверху вниз.
4. Ввести название фильма и API-ключ OMDb (получить ключ можно на https://www.omdbapi.com/).

## Ветки

- `master` — базовый вариант: ключ вводится с клавиатуры, не сохраняется в файлах.
- `movie-output-feature` — небольшое улучшение вывода, влито в `master`.
- `env-feature` — ключ хранится в `.env` через `python-dotenv`. Ветка не влита в `master`.
